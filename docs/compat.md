# Claude Code compatibility (RFC 10.2)

**Verified against:** Claude Code **2.1.316**, macOS (darwin/arm64), 2026-11-02.
**How:** `claude --help` plus three live `claude -p --model haiku` calls in a scratch git repo
(total cost about $0.03). `smif doctor` re-runs the help-based part on every machine and warns when the
installed version differs from 2.1.316.

## Other agents (ADR-0019)

Codex, OpenCode and Hermes were checked live, as their rows say. The other rows come from reading each agent's source, and the
test fixtures are built from the same reading, so a green test proves only smif's parser. Each of those providers stays
unverified, read only, until a row gives a version a real session checked. `smif doctor` reports these formats as
`unchecked`.
